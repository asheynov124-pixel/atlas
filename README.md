## meridian/

Reference implementation of the Meridian Product Architecture Specification (PAS-001),
revised to v1.1. The spec with its change log is at `meridian/docs/SPEC.md`; the code,
tests and demos are described in `meridian/README.md`. It is a standalone Node 22 /
TypeScript package and does not touch the Expo tree above.
