# atlas
Atlas — knowledge explorer shell. Hop policy + Continuity Odyssey manifest on the Expo runtime.

## discovery/

`discovery/` is **PH Discovery**, a standalone mobile-first PWA prototype: a vertical swipe
feed with taste profiles, Smart Paths, Aspect Capture, and AI search hooks, all running on
a mock data layer, plus Personal Import (your own image, video, and gallery links as native
clips, kept on the device). See [discovery/README.md](discovery/README.md).
