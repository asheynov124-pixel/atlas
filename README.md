# atlas
Atlas — knowledge explorer shell. Hop policy + Continuity Odyssey manifest on the Expo runtime.

## meridian/

The Meridian app: Canvas Workspace UI plus the kernel that implements the Meridian
Product Architecture Specification (PAS-001 v1.1). `cd meridian && npm install && npm start`.
The spec with its change log is at `meridian/docs/SPEC.md`; the app, workflows, tests
and demos are described in `meridian/README.md`. It is a standalone Node 22 / TypeScript
package and does not touch the Expo tree above.
